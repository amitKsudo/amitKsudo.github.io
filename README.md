## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

Check your Node.js version with `node -v`.

Check your npm version with `npm -v`.

### 1. Clone the Repository

`git clone https://github.com/amitKsudo/amit-kumar-data-analyst-portfolio.git`

### 2. Open the Project Directory

`cd amit-kumar-data-analyst-portfolio`

### 3. Install Dependencies

`npm install`

If you encounter a dependency resolution conflict, use:

`npm install --legacy-peer-deps`

### 4. Start the Development Server

`npm run dev`

The portfolio will be available at:

`http://localhost:3000`

Open the address in your browser to view the website.

## Available Scripts

## Deployment

This project is a Vite + React application and can be deployed to platforms such as Vercel or Netlify.

Create a production build with:

`npm run build`

The optimized files will be generated in:

`dist/`

The `dist` directory can then be deployed using a static hosting platform.
